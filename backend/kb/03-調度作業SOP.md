# 調度作業 SOP

給調度中心操作員：怎麼讀這套系統、怎麼決定先派哪一站。

## 一、每輪（每 30 分鐘）的動作

1. 看**供需概況**四個數字：已空站或滿站幾站、預測 1 小時內幾站、空站幾站、滿站幾站。
2. 開**主動警示清單**，依系統排序由上往下處理。清單排序固定，不開放調整：
   - 等級（高 > 中 > 低）
   - 同級比持續輪數（連越久的排前面）
   - 再比建議台數
   - 再比 onset（越早越線的排前面）
3. 高風險站 = 現在就借不到／還不了 → **立即出車**。
4. 中風險站 = 1 小時內會發生 → **1 小時內出車**。
5. 低風險站 = 1～3 小時內 → **列入觀察**，本輪不一定要動。

## 二、台數怎麼看

- 「補 N 台」「取 N 台」= 讓這站回到**這個時段的常態水位**所需的車輛數，不是「補到剛好脫離紅區」。
- 「常態約 N 台」= 這站這個時段的歷史平均，是台數的目標值。
- 「越線 N 格」= 預測 6 格裡有幾格越線，反映持續程度。

## 三、什麼時候「暫不派車」

系統標「暫不派車（hold）」= 這站現在沒事、預測會掉下去但屬正常作息、且會自行回穩。此時：

- 燈號可能仍是中／低風險（尖峰卡人的事實照顯示）。
- 但**不建議出車** —— 派了也是白跑，車子還沒到水位就自己回穩了。
- 高風險站不會出現 hold；若高風險站算出的台數 ≤ 0，系統改建議「補到安全範圍」。

## 四、潮汐站（conflict = swing）

同一站在 3 小時內從「空站」擺到「滿站」（或反過來）—— 通勤站早尖峰被借空、晚尖峰被還爆。這種站看**時機**調度：抓兩個尖峰之間的空檔補／取，不要在尖峰當下硬派。

## 五、資料信心度

- **模型覆蓋率**：有多少站有預測。掉到 95% 以下，介面會用琥珀色 + 警示圖示提醒，那些沒預測的站不計入下方統計。
- 少數新站（訓練後才增設）沒有模型 embedding，會借鄰站特徵預測，或標「尚無預測」。
- 少數站在查詢時刻之前完全沒有水位紀錄（停站期間），單站頁會顯示「查無該站歷史」。

## 六、這是預測，不是即時真值

- 所有數字來自每 30 分鐘一次的批次預測，不是當下的即時車況。
- 預測愈遠不確定性愈大；下界 q19 是 H=4 校準值，H=6 逐格尚未校準，缺車會被系統性低估 —— 所以每個回應都帶提醒。
- Demo 模式下時間是回放的虛擬時刻，不是真實現在。
